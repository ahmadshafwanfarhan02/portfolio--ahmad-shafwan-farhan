# Ahmad Shafwan Farhan — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. The design uses a dark black/navy base with blue accents and English copy.

## Preview locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `ahmad-shafwan-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your URL will look like `https://YOUR-USERNAME.github.io/ahmad-shafwan-portfolio/`.

## Personalize before publishing
- Replace the generic GitHub URLs (`https://github.com/`) with your actual GitHub profile and repository URLs.
- Add your professional email in the Contact Me section.
- Verify your education details and graduation status.
- Add real organization names, roles, dates, awards, and certificates where indicated.
- Keep only skills you can confidently demonstrate.
- If you have a professional photo, you can replace the `ASF` initials inside `.avatar-placeholder` with an image.
- Update project descriptions and links to match the exact features you have implemented. Avoid claiming features that are not yet complete.
